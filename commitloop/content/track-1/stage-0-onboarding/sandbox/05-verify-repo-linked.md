After your Project step (or if you've already created the repo), connect it to CommitLoop so your commits register as progress.

## Link the repository

1. Open your **CommitLoop dashboard**.
2. Connect your **GitHub account** if you haven't already.
3. Select your Track 1 repository (owner + repo name).
4. Save — then refresh. Your pushed commits should appear in the activity feed.

If nothing shows up, check:

- The repo is **public** (or CommitLoop has access).
- You **pushed** after committing — local-only commits aren't visible remotely.
- The linked repo name matches exactly (`you/fitness-tracker`, not a typo).

This link is how CommitLoop knows your GitHub history is *your* project work — not a sandbox folder on your laptop.
