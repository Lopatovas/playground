## Get your environment working

This Sandbox walks you through setting up Git and making a throwaway first commit. Work in a **scratch folder** — not your real project yet. The goal is muscle memory, not a deliverable.

If a command fails, **read the message** and search for it before skipping ahead. That pattern — try, fail, research, fix — is how every stage works.

Run each command in your terminal, then answer the checkpoint to confirm you understand what just happened. You can revisit any step using the numbered dots above.
