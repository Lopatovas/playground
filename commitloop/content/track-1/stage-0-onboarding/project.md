## 1. Create the repository on GitHub

- Click **New repository** on GitHub.
- Name it for your domain: `fitness-tracker`, `recipe-book`, `finance-app`, etc.
- Make it **public** (so CommitLoop and mentors can see your activity).
- Check **Add a README file** so the repo isn't empty.

## 2. Clone it to your machine

```bash
git clone https://github.com/you/your-repo.git
cd your-repo
```

You now have a local copy connected to GitHub via `origin`.

## 3. Write your one-sentence README

Open `README.md` and replace it with a clear description of what your app will do and the "thing" it manages. For example:

```markdown
# Fitness Tracker

A full-stack app to log workouts and see weekly progress.
Built during CommitLoop Track 1.
```

## 4. Commit and push

```bash
git add README.md
git commit -m "Describe project domain in README"
git push
```

## 5. Link your repo in CommitLoop

In your CommitLoop dashboard, connect GitHub and link this repository (owner + name). Then refresh — your commit should register.

## Outcome

You are inside a working codebase, GitHub is connected, and CommitLoop can see your activity. You're ready for Stage 1 — Git & Collaboration, where Git becomes a daily habit.
