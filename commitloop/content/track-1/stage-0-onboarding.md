# Stage 0 — Onboarding

**Goal:** Enter a working engineering environment.

## Lesson

You are not starting a course. You are starting a project that will exist for months.

Today you set up:

- A GitHub account (if needed)
- A dedicated repository for your CommitLoop project
- A local development environment
- Your first commit

GitHub is the source of truth. CommitLoop reads your repo — not your intentions.

## Sandbox Task

1. Create a new public repository on GitHub named for your project domain (e.g. `fitness-tracker`, `booking-app`).
2. Add a `README.md` with one sentence: what your app will do.
3. Clone locally, open in your editor, run `git status`.

No application code required yet.

## Project Implementation

In your CommitLoop dashboard:

1. Connect GitHub.
2. Link your new repository (owner + name).
3. Push your README commit.

**Outcome:** You are inside a working codebase with GitHub connected.

## Checklist

- [ ] GitHub repo created
- [ ] Repo cloned locally
- [ ] README describes your project domain
- [ ] First commit pushed
- [ ] Repo linked in CommitLoop dashboard
