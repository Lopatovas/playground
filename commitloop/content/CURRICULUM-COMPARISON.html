Track 1 curriculum — visual comparison

Stages broken into lessons (and CommitLoop sandbox / quiz / project layers). One evolving student repo throughout.

Yes — CommitLoop breaks every stage into lessons. Each stage in stage.json has four layers:
  1. Lessons — lesson.pages[] markdown pages (typically 3–6 per stage). Tooling lessons come first when a stage introduces DevTools, Postman, curl, or DB tools — students need validation before the subject.
  2. Sandbox — sandbox.steps[] guided drills with checkpoints (typically 5)
  3. Quiz — quiz.questions[] — max 5 questions, 80% to pass; every question must be answerable from that stage’s lessons + sandbox only
  4. Project — checklist[] items student must complete in their repo
Loop: Lesson → Sandbox → Quiz → Project, then unlock next stage.
