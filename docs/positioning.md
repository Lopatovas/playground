# CommitLoop — Positioning (One Page)

**Domain:** commitloop.dev  
**Tagline:** One loop. One project. Every day.  
**Category:** Accountability-first engineering apprenticeship

---

## What CommitLoop Is

CommitLoop is not a bootcamp and not an LMS. It is a system that helps students **consistently execute** — building one evolving application per track while developing professional engineering habits. Tracks are independent: Track 1 for full-stack fundamentals, Track 2 for frontend depth (HTML → React → React Native) — no required order.

Every concept follows the same loop:

**Lesson → Sandbox → Project Implementation**

GitHub is the source of truth. Progress is measured by real commits, assignment completion, and project evolution — not video watch time.

**Core promise:** Consistency → Accountability → Skill

**Graduation outcome:** A deployed application, a Git history that shows growth, and the habits to keep building independently.

---

## Positioning Statement

For **aspiring developers who keep starting but never shipping**, CommitLoop is an **accountability-driven apprenticeship** that combines a structured curriculum, daily GitHub execution, and human mentors — unlike bootcamps that optimize for content consumption or streak apps that track activity without teaching anything.

## Target Audience

### Primary — "The Tutorial Graveyard" (launch focus)

| | |
|---|---|
| **Who** | Career switchers and self-taught learners, 25–40, who've done Codecademy/YouTube/freeCodeCamp but have no deployed project |
| **Pain** | Tutorial paralysis, restarted projects, inconsistent practice, weak GitHub profile |
| **Trigger** | Failed job applications, "I know React but can't build alone," guilt about another abandoned side project |
| **Why CommitLoop** | One project with no resets forces integration; daily commit rule creates structure they can't give themselves |
| **Willingness to pay** | Medium-high — already spent on courses; will pay for accountability + mentorship |

### Secondary — "The Undercooked Bootcamp Grad"

| | |
|---|---|
| **Who** | Bootcamp or CS grads who can pass exercises but struggle to evolve a codebase independently |
| **Pain** | Portfolio projects are clones; no evidence of sustained building; weak Git workflow |
| **Why CommitLoop** | Workflow progression (commits → branches → PRs → reviews) and one long arc project |

### Tertiary — "The Returning Builder"

| | |
|---|---|
| **Who** | Developers re-entering after a gap (parental leave, career pivot, burnout recovery) |
| **Pain** | Lost confidence and rhythm; needs external structure to rebuild habits |
| **Why CommitLoop** | Low daily minimum (one meaningful commit) values consistency over intensity |

### Not for (yet)

- Complete beginners expecting to be spoon-fed
- Developers seeking AI-only tutoring with no human accountability
- Employers looking for compliance apprenticeship management (ApprentiScope, GoSprout)
- Learners who want many small disposable projects

| They optimize for… | CommitLoop optimizes for… |

## Pricing Hypothesis

Mentor time and cohort intimacy are the cost drivers. Price below bootcamps ($5k–$15k), above passive courses ($20–$50/mo).

### Launch model — Founding Cohort (recommended)

| Tier | Price | Includes |
|---|---|---|
| **Founding Cohort** | **$149/mo** × 6 months (~$894 total) | Full curriculum, GitHub accountability dashboard, Discord community, mentor office hours (group), async PR reviews (limited) |
| **Founding Cohort +** | **$249/mo** × 6 months (~$1,494 total) | Everything above + monthly 1:1 mentor call, priority async support, personalized project domain guidance |

**Launch discount:** First cohort at 30% off ($104/mo / $174/mo) in exchange for testimonials, case studies, and product feedback.

**Cohort cap:** 20–30 students. Scarcity is real — mentor capacity, not marketing.

### Post-launch (hypothesis, validate after cohort 1)

| Tier | Price | Role |
|---|---|---|
| **Self-guided** | $49/mo | Curriculum + GitHub tracking only. No mentor. Validates accountability engine without mentor cost. |
| **Cohort** | $199/mo | Standard cohort with group mentorship |
| **Cohort +** | $299/mo | 1:1 mentorship layer |

### What not to do at launch

- Income share agreements (legal overhead, wrong audience early)
- Free forever (attracts non-committers; undermines accountability brand)
- Per-seat enterprise pricing (wrong stage)

### Success metrics for pricing validation

- Cohort 1: ≥70% complete Stage 4 (deployment)
- ≥60% daily active commit rate (weekday average)
- ≥50% would pay full price after founding discount
- Mentor hours per student ≤4h/month at cohort tier (sustainable unit economics)

## Launch Messaging

### Hero

> **Stop collecting certificates. Start shipping code.**  
> CommitLoop is an engineering apprenticeship where you build one real app — one meaningful commit at a time.

### Problem (landing page)

You've started more courses than you can count. You've cloned the to-do app twice. Your GitHub is a graveyard of README-only repos.

The problem isn't missing content. It's missing **accountability**.

### Solution (3 bullets)

1. **One project. No resets.** Every concept integrates into your app — a booking system, finance tracker, or whatever domain you choose.
2. **The CommitLoop.** Lesson → Sandbox → Project. Learn it, practice it, ship it in your codebase.
3. **GitHub doesn't lie.** One meaningful commit per day. Mentors see your activity. Streaks measure execution, not motivation.

### Proof points (use as earned)

- Deployed full-stack application at graduation
- Git history showing months of incremental growth
- Professional workflow progression: direct commits → feature branches → PRs → reviews

### Objection handling

| Objection | Response |
|---|---|
| "I can learn for free on YouTube" | You can. CommitLoop is for people who've tried that and still aren't shipping. |
| "One commit a day sounds strict" | It's a minimum, not a maximum. The bar is intentionally low so starting never feels impossible. |
| "Why not a bootcamp?" | Bootcamps sprint. CommitLoop builds habits that last after the program ends. |
| "Why not an AI tutor?" | AI answers questions. CommitLoop makes sure you show up and do the work. |

### Channel messaging (short)

| Channel | Message |
|---|---|
| **Twitter/X** | "Tutorial paralysis is a discipline problem, not a content problem. CommitLoop: one app, daily commits, real mentors." |
| **LinkedIn** | "Career switchers don't need another course. They need a system that makes them build every day until they have a deployed app." |
| **Reddit (r/learnprogramming)** | Honest post: "I built a platform around the one thing that actually worked for me — one project, no resets, daily commits." |
| **Dev.to** | Long-form: "Why I stopped resetting projects and started measuring GitHub instead of Udemy progress." |

### Launch sequence (90 days)

1. **Weeks 1–2:** Landing page + waitlist at commitloop.dev. Lead magnet: "The CommitLoop: why Lesson → Sandbox → Project beats tutorials."
2. **Weeks 3–6:** Build MVP (auth, GitHub integration, curriculum Stage 0–2, mentor dashboard). Recruit 2–3 mentors from network.
3. **Weeks 7–8:** Private beta with 5–10 students. Stress-test accountability rules and mentor load.
4. **Weeks 9–12:** Open founding cohort (20 seats). Close waitlist with clear start date and refund policy.
5. **Ongoing:** Weekly student ship logs (public, with permission). Let GitHub activity be the marketing.

- **Consistency over intensity.** Celebrate showing up, not heroics.
