# Epic: Brand

Finite return loop. 0 is a real win. 1–5 stack.

## In

- Per-class Brand track. Win N unlocks N+1.
- Draft rungs from the spec (elites earlier, rest heals less, start buff, dead starter card, door phase / verb punch).
- Brand is not bought with Runestones.
- Game remains beatable at 0.

## Out

- Endless numbers. Daily runs.

## Done

Tests: Brand 0 has no extra rules; Brand 3 applies the start buff; the other class’s Brand is untouched.
