# Epic: Sortie

One act, ~10 nodes, 2–3 branches. The dark.

## In

- Map graph from `tuning.json` (`mapNodes`).
- Node types: fight, elite, shop, rest, event, treasure, door.
- Rewards: 1 of 3 class cards or skip. Gold. Relic hook (can be thin).
- Shop sells this class only. Rest / remove as spec.
- `RunService` owns cursor, deck, gold, HP between fights.
- Door is the boss fight (door enemy can be a stub until content list).

## Out

- Ledger spend (Hold). Brand modifiers (Brand). Pretty map art beyond bible plates.

## Done

A scripted run walks a path, fights twice, hits a shop, and dies or reaches the door without opening the editor.
