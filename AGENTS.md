# Agent Instructions

This repo is used for AI-assisted micro-projects.

For every meaningful project branch:

1. Build the smallest useful version.
2. Keep project docs current.
3. Leave enough context for later review on a laptop.

Required docs for each project:

- `docs/project-brief.md`
- `docs/implementation-log.md`
- `docs/decisions.md`
- `docs/validation-notes.md`
- `docs/next-steps.md`
- `docs/cabinet-summary.md`

Keep docs concise. Write what changed, why it changed, how to run it, what still needs validation, and whether the idea looks promising.

`docs/cabinet-summary.md` is the short page meant to be pulled into a central Cabinet project.
