# AI Project Playground

This repo is a place for small AI-assisted project experiments.

The goal is simple:

- create micro-projects quickly
- let agents document what they did
- review promising work later from a Cabinet-style knowledge base

Start with:

- `AGENTS.md` - standing instructions for coding agents
- `docs/ai-lab-workflow.md` - how project docs flow into Cabinet
- `docs/templates/` - reusable project and Cabinet summary templates
